# 100 Days of Cloud Challenge – KodeKloud

Welcome to my **100 Days of Cloud Challenge** repository 🚀  
This repo documents my hands-on journey through cloud infrastructure using **AWS and Azure**, powered by the **KodeKloud 100 Days of Cloud Challenge**.

This challenge is not about passive learning — it’s about **doing**, **breaking**, **fixing**, and **understanding cloud services deeply**, using real-world, task-driven scenarios.

---

## 📌 Challenge Overview

The **100 Days of Cloud Challenge** is divided into **two structured phases**:

### 🔹 Phase 1: AWS Cloud (Days 1–50)
Focused on building strong foundations and operational confidence in **Amazon Web Services**, covering services such as:
- EC2
- VPC & Subnets
- Security Groups
- EBS & Snapshots
- AMIs
- Elastic IPs
- IAM (Users, Policies, Permissions)
- Networking components
- Resource lifecycle management
- Cost-awareness and optimization

### 🔹 Phase 2: Azure Cloud (Days 51–100)
Focused on equivalent and advanced concepts in **Microsoft Azure**, including:
- Virtual Machines
- VNets & Subnets
- Network Security Groups
- Disks & Snapshots
- Azure IAM concepts
- Resource Groups
- Identity & access control
- Cloud governance and security

---

## 🎯 Why This Challenge?

Years ago, I learned cloud primarily by **clicking around the console**.  
This time, I made a deliberate decision to do things differently.

> **Every task in this repository is completed using the CLI.**

Why?
- To gain **deeper understanding** of how cloud services actually work
- To improve **speed, automation, and reproducibility**
- To build skills that scale in **real DevOps and Cloud Engineering roles**
- To reduce human error and improve cost control
